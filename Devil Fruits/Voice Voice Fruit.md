# Voice Voice Fruit

*Special Paramecia (consumed)*

| | |
| --- | --- |
| **Owner** | The Emperor of [[Decibella Kingdom]] |
| **Registry** | [[Devil Fruits]] |

## Description

Lets the user compel obedience from anyone who can hear them (the "Decibel Decree"). A commoner owned it first; the Emperor killed that commoner and took the power ([[Session 014 — The Decibel Decree|Session 14]], DM, 2026-10-02). If the Emperor wakes fully, anyone hearing him will "bow." The Emperor sleeps almost all the time.
