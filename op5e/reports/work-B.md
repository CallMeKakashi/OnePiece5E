## 5. Skills and Tools (scripts/skills-and-tools.mjs, one import + one call in compendium.mjs init)
dnd5e 5.1.10: tool checks go through Actor5e#rollSkillTool; the dialog only chooses the ability, not a skill; dnd5e adds advantage only when the caller passes `config.skill` with both proficiencies. Hook `dnd5e.preRollToolV2(config)` carries subject, tool, ability, advantage. Implemented: advantage when tool value >= 1 (expertise counts) and any skill with value >= 1 shares the check's ability (or the passed skill). World setting `toolSkillAdvantage` (default on). Limitation: ability changed in the dialog after opening does not re-evaluate; the native doubleProf cannot be turned off by the setting.
